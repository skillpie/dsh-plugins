# 精选插件

**发现好插件,只需要一个入口。**

DSH 的好东西散落在各处——有的藏在 GitHub,有的只在群里传,有的名字平平无奇但用起来离不开。**精选插件**把社区里真正值得用的插件收进一个清单,打开插件页就能逛、能搜、能一键装上。

> 装上它之后,你大概就不会想卸载了。

---

## 你会得到什么

**一个标签页,逛完全部好货**

打开「插件」页面,点「精选插件」——卡片瀑布流铺开,每个插件都带图标、简介、版本号和截图预览。不用一个个去翻 GitHub README。

**搜得到,筛得准**

- 顶部搜索框:输名字、简介或者标签,边打边过滤
- 标签栏:想看「数据库」相关的?点一下就够了
- 已装过的插件,右上角直接标「✓ 已安装」,不会重复装

**点一下,就装好了**

不用填包名、不用复制命令、不用确认一堆弹窗。点「安装」,进度条就开始走。

**先看 README,再决定**

点插件标题,弹窗里直接显示它的完整说明文档——排版整齐,图片、表格、链接都正常。看完再装,不踩坑。

---

## 不用它的时候

不装它也完全没关系。

如果你用过某些内置了这个板块的插件,点开「精选插件」时会**自动帮你装好完整版**——你什么都不用做。

偶尔屏幕上多一个标签页?那是「精选插件」在正常工作。不喜欢的话,在插件列表里把它卸掉就好,下次也不会再自动装。

## 常见问题

**会收集我的数据吗?**
不会。清单是公开的,你装了什么只记录在本机,用来显示「已安装」标记。

**插件列表是写死的吗?**
不是。清单从公开仓库实时拉取,新插件进来你刷新页面就能看到,不用等更新。

**我可以只装某几个插件吗?**
当然。这里只是逛街的地方,装不装、装哪个,完全看你。
